# Fix Header Link (Unraid)

This is a simple plugin for Unraid that replaces the unraid.net link in the WebGUI header with a link back to the WebGUI start page.

## Fork

This is a community-maintained fork of [dkaser/unraid-header-fix](https://github.com/dkaser/unraid-header-fix), which reached End of Support in October 2026. It adds support for the unified `<unraid-header>` introduced in Unraid 7.4 while keeping compatibility with the legacy header (7.1 - 7.3).

Install URL:

```
https://raw.githubusercontent.com/EllipticSet/unraid-header-fix/main/plugin/header-fix.plg
```

## Support

Report problems at https://github.com/EllipticSet/unraid-header-fix/issues.

## Rollback

Remove the plugin from the Plugins page. To go back to the original plugin, install `https://raw.githubusercontent.com/dkaser/unraid-header-fix/main/plugin/header-fix.plg` (no longer maintained, and it does nothing on Unraid 7.4).
